# 任務：圖包轉 A4 列印檔（範例）

> 這是格式範例。實際任務請複製 `tasks/_template/`。

## 目標

把一組插畫圖包整理成可以直接送印的 A4 檔案，並另外合併成一份 PDF 方便預覽。

## 輸入

- 位置：`in/`
- 檔案類型與數量：PSD、PNG、JPG 混合，約 20 張，直式和橫式都有

## 輸出規格

| 項目 | 規格 |
|---|---|
| 尺寸 | A4，300 dpi（直式 2480×3508 px，橫式 3508×2480 px） |
| 方向 | 依原圖方向自動選擇 |
| 縮放方式 | 等比縮放，完整保留畫面，置中留白 |
| 留白或背景色 | 白色 |
| 格式 | 每張一個 JPG（品質 92），另外合併成 `all.pdf` |
| 色彩 | 保持原樣 |
| 命名規則 | 與原檔同名 |

## 編修步驟

1. `scripts/to-a4.sh in out --orient auto --format jpg --quality 92`
2. 用 `pdfcraft-cli run doc_combine` 依檔名順序合併 `out/*.jpg`，輸出成 `out/all.pdf`

## 驗收標準

- [ ] `out/` 中的 JPG 數量與 `in/` 的檔案數量相同
- [ ] 每張都是 2480×3508 或 3508×2480，dpi 300
- [ ] 小於 A4 的原圖要在報告中列出（放大後可能模糊）
- [ ] `all.pdf` 的頁數等於 JPG 數量
